- `README.md`

## 새 PC 준비
- 위 정본과 루트 AI 지침의 실제 실행·검사 절차를 먼저 확인한다. 파일 존재만 확인했으며 버전·명령의 실행 성공은 아직 검증하지 않았다.
- 프로젝트가 고정한 런타임·lockfile을 사용한다. 전역 도구의 최신 버전으로 무조건 바꾸지 않는다.
- 필요한 CLI·확장·MCP를 기존 설정에서 확인하고 설치·인증한다. 설정 목록과 실제 설치 상태는 다르다.
- .env, API 키, 로그인 토큰, 로컬 DB, PC별 경로는 Git 기록과 분리한다. 실제 값 대신 필요한 변수 이름과 예제 파일 경로만 기록한다.
- 새로 확인한 설치·실행·검사 절차는 프로젝트 정본 문서에 반영하고 이 목록에 연결한다.
