# mdds: 공통 작업기록

## 다른 PC에서 이어가기
1. 작업하던 PC에서 코드와 최신 인계 기록을 함께 커밋·푸시한다.
2. 다른 PC에서 올바른 브랜치의 최신 변경을 가져온다. 미커밋 작업이 있으면 먼저 보존한다.
3. AI에게 “AGENTS.md와 .ai-context의 기록을 읽고 실제 파일과 대조한 뒤 이어서 작업해”라고 요청한다.
4. 도구 설치·로그인은 PC별로 준비한다. Git은 실행 중인 AI 세션을 복제하지 않는다.

## 파일 역할
- HANDOFF.md: 현재 작업의 요청·진행·검사·다음 행동.
- DECISIONS.md: 장기 유지할 결정 또는 기존 정본 문서 참조.
- ENVIRONMENT.md: 실행 환경의 정본 파일 위치와 새 PC 확인 절차.

기존 작업일지가 있으면 보존하고 여기에 연결한다. 기록을 읽었다는 이유만으로 검사 통과나 원격 동기화 완료를 주장하지 않는다. 이 폴더는 도구 설정·작업기록의 공유 통로이며 전체 대화 저장소가 아니다.
